—— v1.6 单元打标（命令词切分） ——
V / W视频标注模式 / 单元打标模式（顶部按钮同步高亮；右侧面板页签随模式切换；除 ←/→ 与数字键外其余键两模式通用）
标注单元ASR 命令词把响段切开：命令词单元（令）+ 空隙单元（隙）+ 响段外命令词（令·asr_only）；空隙全部进入列表由人工逐条判断，不设时长门槛
← / →（单元模式，下轴）v2.1：上一个 / 下一个相邻单元（不筛已标/未标、到头尾不循环），落点=单元起点并自动播放该段（到段尾自停，v1.7）；打完标自动跳下一个未标不变；↑ 切上轴后仍是 ±5s 粗调
1~8（单元模式直接按 / 弹窗内）上升 / 上升一点 / 下降 / 下降一点 / 停 / 无关段 / 自定义（7 自动聚焦文本框，输入后 Enter 提交）/ 无人声段（8=该单元内没有人说话）；打完自动跳下一个未标单元
Enter（单元模式）打开当前单元打标弹窗；语音文本自动预填（空隙=非命令片段，命令词=词本身），整句灰字参考
S（单元模式）播放头处把当前单元切成两半（手工单元），两半回到未标态
M（单元模式）把当前单元与下一个相邻单元手动合并成一条（任意间隔都并）：文本/命令词空格拼接，已标标签去重后用 + 连接（如 stop+up），两边都未标则合并后仍未标；想和上一段并就先用 ← 选中上一段再按 M
A（单元模式）新建片段：先用 I/O 在空白处定入点与出点，按 A 把两点合成一条手工单元（补生成单元没覆盖的空隙）；入出点间隔 < 0.05s 或与已有单元重叠则拒绝；成段后自动选中该新行，可直接用 1~8 打标。视频标注模式下按 A 会提示先按 W 切到单元模式（Enter/S/M/Delete 同样只在单元模式生效）
Delete（单元模式）删除当前单元：生成单元记入 removed_unit_ids 不再出现，手工单元直接移除
单元行右侧 ✕不选中也能删：行内删除该片段，作用范围与 Delete 相同（生成单元记入 removed_unit_ids，手工单元直接移除）；删掉与别的片段重叠的旧预标注行就用它。悬停行才显眼，点击不会选中该行的文本框
单元列表文本框右侧“标注单元”页签内可直接编辑每个单元的文本，失焦即保存
🎤 人声轨按钮开启后视频静音、独立播放 result/vocal_separation/…/vocals.wav，seek/暂停/倍速跟随视频；无分离文件自动回退原音
单元层配色命令词单元=蓝框、空隙=浅灰、手工=紫；绿系=上升、红系=下降、青=停、紫=自定义、深灰半透明=无关段、蓝灰=无人声段；金框=当前单元；拖动单元两端改边界
—— v1.7 段内播放（单元模式） ——
选中/跳到单元自动从该单元起点播放，播到终点自动停（点列表行、时间轴单元块、←/→ 跳转、打完标自动跳下一段时都触发；音源跟随 🎤 开关）；手动点时间轴则取消段约束
空格（单元模式）只播当前单元那一段（到段尾自停）；播放中再按=暂停；v2.1 锚点语义见下方 v2.1 段
—— v1.8 近间隔合并（间隔 < 0.5s 并一条） ——
自动合并相邻两个单元间隔 < 0.5s（含无缝衔接）自动合成一条：连说命令词标签用 + 拼接（如 stop+up），空隙并入邻近单元；一条合并单元只打一个标签，需要分开标时用 S 在播放头处切分；间隔 ≥ 0.5s 的两段想并成一条时选中前一段按 M 手动合并
已标数据合并后旧单元已打的标签/状态自动继承到合并行，不会丢失；合并行被 S 切分后各子块回到未标态重新打标
—— v2.1 波形条 / 锚点播放 / 相邻跳转 / 人声基准 ——
人声波形条（时间轴顶部紫条）vocals.wav 的 20ms 音量包络（V/W 模式都显示，全局视野不放大）；点击=定位、按住拖动=连续快扫；无 vocals.wav 时显示“无人声波形数据”。服务端缓存在 result/annotation_cache/waveforms/
空格锚点播放（单元模式）点过时间轴/波形条上某单元内部的某点后按空格 → 从该点播到该单元段尾自动停；段尾停后再按空格 → 回到该单元起点重播整段；点的位置在所有段之外再按空格 → 播选中单元整段；点列表行 / 单元块 / ←→ 跳转 / 打完标自动跳 → 一律仍是整段语义
← / →（单元模式）改为跳相邻单元（不管有没有打过标，到头尾提示不循环）；打完标自动跳“下一个未标”保持不变
响段基准改人声轨新视频的响段/单元由人声分离轨 vocals.wav 的响度段切分（避免吊机噪音等把整段误判为响段）；已有标注单元的视频自动锁定原整轨基准，存量标注不受影响
—— v2.6 人工确认标志 ——
Q确认当前模式：视频 [V] 模式下点亮 V（动作列表已人工确认），单元 [W] 模式下点亮 U（标注单元已人工确认）。两个标志互相独立，再按一次 Q 即取消，无弹窗无二次确认；不设任何门槛（标没标全都能确认），也不因后续内容改动自动失效——一切以你按下的这一下为准
左侧列表行首小灯V/U 两个圆灯：绿实心=该模式已确认，灰空心=未确认；选中文件即从磁盘读取真实状态
列表顶部「已确认 x / 已标注 n」分母只统计有标注内容的文件（actions 或 speech_units 非空），分子=V 与 U 都确认的文件数；悬停可看两个模式各自的确认数
列表顶部「未确认」勾选只看「有标注但还没全部确认」的文件，默认关闭；只隐藏行，不改变排序；批量确认/批量跳转一律不做
落盘位置写在标注 json 顶层的 confirm_video / confirm_unit 两个布尔字段；缺字段=未确认，存量文件无需迁移

标记自动保存到 result/annotations/<日期文件夹>/<视频名>.json（单元结果存 speech_units 字段；actions、voice_segments 旧字段一律不动）
